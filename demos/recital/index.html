Voices

  • Python, reference/make_vectors.py, writes the state hash.
  • Swift 6.4.1 embedded WebAssembly SDK builds CommitmentGuest. The guest calls State.commitment from CanonicalBytes. The 60 MB WASI command is not this file.
  • Rust commitment-reader 0.1.0, wasm32-unknown-unknown, hashes the same profile outside the Swift process.
