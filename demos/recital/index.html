Commitment recital

One public piece. Python wrote the expected hashes. This page runs two modules that construct the synthetic-base state themselves: the Rust reader, and a Swift guest built with the embedded WebAssembly SDK from the same canonical bytes. Neither module is given the other's hex. This page does not issue a capability or commit.

The modules are commitment_reader.wasm and commitment_guest.wasm next to this page.

Voices

  • Python, reference/make_vectors.py and reference/make_practice_vectors.py, writes the hashes.
  • Swift 6.4.1 embedded WebAssembly SDK, CommitmentGuest, constructs the state in this page and writes 64 hex bytes. The 60 MB WASI command is a separate probe and is not loaded here.
  • Rust commitment-reader 0.1.0, wasm32-unknown-unknown, constructs the same state and the empty practice log.
