# Roadmap — proposals only

Foundation v0.1 provides the current small semantic reference and post-hoc evidence map. Possible later phases are a local reference runtime, public API contract, storage abstraction, Cloudflare/R2 adapter, Apple Core AI execution adapter, virtualization/microkernel authority boundary, and broader cognitive/differential execution research.

The one recorded move is the static recital host in `docs/cloudflare-host.md`. It adds a page beside the existing research documents, such as `https://ergentics.com/research/propulsion.html`. It does not replace that site. A temporary `workers.dev` preview is recorded there. The zone path beside that research page is not attached. R2 stays unused on that move. The production store stays unimplemented until it has its own contract for what is stored, who may write it, and how a reader checks current authority. The other phases have not started. Each still needs its own design, controls, and review. Cloud infrastructure is storage and execution infrastructure, not semantic authority. A numerical/model backend is not semantic authority. The intended future verifier/isolation side is subject to later design and empirical validation; no microkernel enforcement exists in v0.1.

No future project must resolve E26's UNKNOWNs first. Reopening that line requires an explicit new question and independently motivated intervention with new frozen controls, not an automatic E27 or a largest-timer optimization. The open questions are listed in [E27 candidates](e27-candidates.md). None is nominated.
